## EXPLAIN THE  WHOLE SYSTEM

## ONLINE STORE : customer placing an order

# Step 1:
Request customer Name, check if customer input Name if yes, request for KYC Elseif no name in input Name, print name required to proceed

# Step 2:
Request customer delivery information; house address and phone Number, check if delivery information is valid Elseif request customer to verify delivery information

# Step 3: 
Request customer to place order for product(puma shoe) , check if order is available Elseif print product out of stock and if customer need another product

# step 4:
Request quantity/unit needed by customer, check if the quantity/unit is available Elseif print order exceed available unit in stock and print check back in an hour time

# Step 5:
Request customer to add product to cart, if yes proceed to checkout Elseif print continue shopping

# step 6:
calculate the total unit of product ordered,by multiplying the total unit selected by product cost price 

# Step 7:
Saved all customer information data and product ordered in cart

# Step 8:
 Request for mode of payment if card or bank transfer and verify  selected mode 

# Step 9:
Request for customer payment information, validate customer payment information if card mode is selected and confirm transfer payment if bank transfer mode is selected and confirm amount payed by  matching the total cost price of product ordered with payment made, Elseif print payment information invalid for card payment mode, try again and re-verify payment details and limit re-try to 4 try after which request customer to try again in 24hours

# Step 10:
if payment is successful print ordered confirmed and  thanks for shopping with us
